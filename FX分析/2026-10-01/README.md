# USD/JPY 本日の傾向 - 2026-10-01

## 結論
ロング:ショート = 52:48 (前回9/30の55:45からロング比率をさらにやや引き下げ、ほぼ中立に近い水準)

9/30のNY市場では、米8月PCEコア価格指数が予想を下回ったことで10月FOMCでの追加利上げ観測が一時7割前後から5割以下まで急低下し、ウィリアムズNY連銀総裁も「年内あと1回」の利上げに言及するにとどめ10月利上げに前のめりな姿勢を示さなかった。これはドルにはマイナス材料だが、一方でADP雇用統計(+9万人、予想上回り6月来で最高)・GDP確報値(2.2%上方修正)という強い実体経済データ、および米10年債利回りが5.29%と19年ぶり高水準を更に更新したことはドルを支える方向に働いており、市場は綱引き状態でドル円は156円台後半〜157円台前半のレンジに収まった。前日まで相場を揺らしていたイラン情勢・原油急伸という地政学リスク要因は本日の情報収集では新たな続報が確認できず、材料としては後景化している。加えて本日は日銀短観(9月調査)の発表を控え、事前予想では大企業製造業の改善(前回+22→+25程度)が見込まれており、日銀の追加利上げ期待をわずかに支える方向。FRBの10月利上げ確度低下とBOJのタカ派期待維持がともにロング材料を弱める一方、金利差(10年債利回り高止まり)と強い米経済指標がロングを支える構図で、前回からさらにロング比率をわずかに引き下げ、ほぼ中立に近い比率とした。
