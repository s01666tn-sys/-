# USD/JPY 本日の傾向 - 2026-09-17

## 結論
ロング:ショート = 60:40 (前回9/16の56:44からロング方向へ再修正)

最大の変化点は、9/16(JST 9/17未明)のFOMCで25bp利上げ(FF金利誘導目標3.50〜3.75%→3.75〜4.00%)が全会一致で決定され、約3年ぶりの利上げとなったこと。ウォーシュ議長はインフレの高止まりリスクを強調し、SEP(経済見通し)・ドットチャートの改定でも年内追加利上げの可能性が示唆されるなど、「利上げ実施」だけでなく「タカ派的な内容」であった点が重要。これを受け東京市場では9/17朝、外為どっとコムが「円安再燃のリスク、焦点は日銀に」との見出しでドル円予想レンジを155.500〜157.000円(前日の153.500〜154.900円想定から明確に切り上げ)としており、市場のドル買い地合いが強まっていることが確認できる。一方で原油価格はサウジのパイプライン復旧見通し(米エネルギー長官発言)を受けて9/16に反落し、インフレ懸念の一段の高まりには歯止めがかかった。また米国株はFOMC後に急落(ダウ▲1.21%、銀行株は2月以来の下げ)しリスクオフ色もあるが、金利差要因がこれを上回りドル高・円安方向へ効いている。ただし9/17〜18の日銀会合(1.25%への利上げがほぼ確実視)と18日の植田総裁会見、財務省の介入警戒発言が155円台後半〜157円で強く意識される局面であるため、大幅なロング転換は避け60:40にとどめた。

## 前回分析との比較
前回(9/16)はロング:ショート=56:44とし、FOMC結果発表を控えてFedWatch等の利上げ確率が83〜92%まで急上昇したことを主因に小幅ロング優勢としていた。今回(9/17)にかけての最大の変化点は、(1)FOMCが実際に25bp利上げを全会一致で決定し、かつウォーシュ議長発言・SEP改定を通じて「タカ派的な内容」であったことが確認されたこと、(2)これを受けて外為どっとコムなど識者のドル円予想レンジが155.500〜157.000円へ切り上がり、「円安再燃のリスク」が明示的に指摘されるようになったこと、である。一方で、原油価格はサウジパイプラインの早期復旧観測を受けて反落し、これまでのインフレ・金利上昇を通じたドル買い材料はやや後退した。また米国株がFOMC後に急落しリスクオフ色も強まっているが、今回は金利差拡大の思惑がこれを上回りドル高方向に効いているとみて、比率は56:44から60:40へロング方向にさらに修正した。日銀会合(9/17〜18)という大型イベントを控えていることから、これ以上の大幅なロング転換は回避した。
