# USD/JPY 本日の傾向 - 2026-09-07

## 結論
ロング:ショート = 32:68 (前回9/6の33:67からショート優勢をわずかに強化。BOJ利上げ観測の前倒し観測と実勢の下値模索継続を重視)

本日(9/7、月曜)は週明けの取引再開日。9/5(金)のドル円実勢は156.23〜156.25円で引け、9/4の157.03円からさらに円高方向に進んでおり、160円台からの調整局面が継続している。この間、仏Natixisが日銀の追加利上げ予想を従来の10月見通しから9/17〜18会合へ前倒しするなど、市場では日銀タカ派化を織り込む動きが強まりつつある。一方、米金利面では9/4発表の8月雇用統計(NFP+16.2万人、予想+5.8万人を大幅に上回る)を受けて9月FOMC利上げ織り込みが一時58%まで上昇したものの、その後の集計では50%台前半とほぼコイントスの水準にとどまり、方向感には乏しい。米10年債利回りも9/4の4.79%から9/5には4.76%へやや低下しており、ドル買い材料としての勢いはやや後退している。株式市場は米国株が9/5にダウ271ドル安と3営業日ぶりに反落した一方、VIXは9/4時点で14.36と落ち着いた水準を維持しており、パニック的なリスクオフには至っていない。CFTC投機筋の円ネットショートについては、直近報道でむしろ拡大(▲63.3千枚→▲92.2千枚、集計時点は検索範囲では確定できず)とする記事があり、仮に事実であれば市場はなお円安方向に傾いていることになるが、これは実勢の円高進行とは逆方向のシグナルであり、ポジションの偏り・巻き戻しリスクとして両にらみで意識する必要がある。今週最大の焦点は9/8(火)の日本4-6月期GDP改定値(上方修正観測)と9/11(金)の米8月CPI(加速予想)であり、この2つの結果次第で潮目が大きく変わり得る。以上を踏まえ、実勢の下値模索継続とBOJタカ派観測の前倒しをやや重視しつつ、米金利面での明確なドル買い材料の後退も考慮し、比率を33:67から32:68へわずかにショート優勢を強めた。
