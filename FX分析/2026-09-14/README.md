# USD/JPY 本日の傾向 - 2026-09-14

## 結論
ロング:ショート = 46:54 (前回9/13の48:52からわずかにショート優勢を強化)

今週はFOMC(9/15〜16)・日銀金融政策決定会合(9/17〜18)という日米中銀イベントが目前に迫り、市場は方向感に乏しい神経質な様子見ムードにある。ドル円は9/13夜〜9/14未明にかけて一時154.48円まで上昇する場面があったものの上値は続かず、9/14朝時点では153円台前半〜154円台前半のレンジで揉み合っている。今回新たに、日銀の9月利上げが金利スワップ市場で「織り込み100%超」とほぼ確実視されていることが確認できた一方、CFTC/IMM投機筋の円ネットポジションが9/8時点で明確にネットロング(+10,796枚)に転換していたことも複数情報源で裏付けられた。前者は円買い材料が出尽くしつつあることを、後者はこれまで意識してきたショートカバー(踏み上げ)による急激な円安リスクがすでに大きく後退したことを示唆し、いずれも従来のロング優勢の根拠をやや弱める方向であるため、比率を48:52からわずかにショート方向(46:54)へ修正した。ただしFOMCの利上げ織り込みも86〜90%と高水準を維持しており、日米双方が利上げする可能性が高い中では方向感自体は限定的とみる。
