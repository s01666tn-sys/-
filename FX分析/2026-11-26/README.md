本日の調査で最も確度の高い新規材料は、米国の10月分PCE(個人所得・消費支出)および7-9月期GDP第2次推定値が11/25に実際に発表されたことである。PCEはコア前年比+3.3%(9月+3.1%から加速、市場予想+3.2%をやや上回る)、ヘッドライン+3.8%(9月+3.6%から加速、月次+0.3%は予想通り)と、インフレがなお高止まり・加速している内容だった。GDP第2次推定値は前期比年率+4.3%に上方修正され、速報値(10/29公表)の+3.4%から大きく上振れした。CME FedWatchベースでは12月8-9日FOMCでの0.25%利上げ(現行3.75〜4.00%レンジから)がおよそ85〜89%の確率で織り込まれていると報じられており、本日の強いGDP・インフレ指標はこの利上げ観測を裏付ける内容と評価できる。経済の底堅さとインフレの粘着性が米金利高止まり・日米金利差拡大の継続を支持するため、ドル優位方向への材料とみてロング優位をやや強化した。一方、UOB Groupの11/24〜25付レポートは短期的には158.80〜159.60円のレンジ・下値圧力を指摘し、1〜3カ月の中期見通しでは依然「円高方向」を示しているとされ、160円接近時の介入警戒という継続材料も解消していないため、比率の変化は55:45の小幅な修正にとどめた。
