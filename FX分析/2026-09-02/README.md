# USD/JPY 本日の傾向 - 2026-09-02

## 結論
ロング:ショート = 61:39 (米イラン軍事衝突再燃を受けた「有事のドル買い」で160円台を回復し、前回9/1の56:44から明確に引き上げ)

最大の変化点は、米国がイランへの空爆を再開し中東(ホルムズ海峡周辺)での軍事衝突が再燃したことである。これを受けて原油価格が急騰(WTI一時78ドル超、Brent82ドル近辺)し、世界的な債券売り(米10年債利回りは4.78〜4.81%まで上昇、2025年1月以来の高水準)とリスクオフの株安が進む一方、ドル円については「有事のドル買い」が優勢となり、9/1に定着に失敗した160円台を9/2朝には160.28円前後まで回復した。ウォーシュ議長に続きウォラーFRB理事もインフレ期待の無秩序化への警戒を示すタカ派発言を行い、9月FOMC利上げ織り込み(CME FedWatchで60〜66%)を下支えしている。一方でG20財務相・中央銀行総裁会議は共同声明の採択を見送り(議長声明のみ)、ベセント米財務長官は改めて日銀に利上げを求め、片山財務相は160円接近が「秩序だっているか」の言及を避けるなど、円安けん制・当局警戒のトーンは継続。日本の10年国債利回りは1996年以来初めて3%に達し、日銀の追加利上げ観測・BOJタカ派材料も強まっている。JOLTS求人件数が予想を下回るなど米雇用の軟化シグナルも出ており、9/4の雇用統計次第で潮目が変わり得る点には留意が必要。以上を踏まえ、直近の実勢価格が有事のドル買いで160円台を回復した事実を重視しつつ、当局けん制・BOJタカ派材料・弱含みの雇用指標をリスク要因として意識し、比率を56:44から61:39へ引き上げた。
