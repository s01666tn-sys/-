# USD/JPY 本日の傾向 - 2026-09-13

## 結論
ロング:ショート = 48:52 (前回9/12の55:45からロング優勢をほぼ解消し拮抗へ)

9/13(日)も為替市場は実質休場であり、本レポートは9/11(金)NY市場引けの地合いの持ち越しと、来週(9/15〜16FOMC、9/17〜18日銀会合)を目前に控えた地合いを指すものと位置付ける。9/11の米8月CPIコア上振れを受けて一時154.48円まで上昇した後、ミシガン大学消費者信頼感指数の予想以上の低下と原油価格の反落が重なり、ドル円は153円台前半(153.24〜153.44円)まで失速して引けた。この「CPI上振れでも上値が続かない」値動きに加え、投機筋の円ポジションがネットショートからネットロングへ転換したとする報道(未確定・複数報道あり要検証)が新たに浮上しており、これまでの明確なロング優勢を維持する根拠が薄れたと判断した。一方でFOMC利上げ織り込みは約9割で高止まりしており、米国株はCPI後に大きく切り返しVIXも急低下するなどリスクオン地合いが強まっていることから、一方的な円高進行を見込む状況でもない。以上を踏まえ、比率を55:45からほぼ拮抗の48:52(僅かにショート優勢)へ修正した。

## 前回分析との比較
前回(9/12)はロング:ショート=55:45とし、CPI上振れ・利上げ織り込み急上昇というドル買い材料と、実際の値動き(154.48円から153円台前半へ失速)の食い違いを踏まえてロング優勢をやや緩めていた。今回(9/13)にかけての追加の変化点は、(1)9/11のドル失速の背景として、原油一服に加えミシガン大学消費者信頼感指数の予想比下振れという新たなドル売り材料が確認できたこと、(2)投機筋の円ポジションがネットショートからネットロングへ転換したとする(未検証ながら)報道が新たに浮上したこと、(3)財経新聞の週間見通しが「日米中銀会合通過後はドル売り・円買いが一服し得る」との視点を示したこと、である。これらは総じてこれまでのロング優勢の根拠をやや弱める方向であり、比率を55:45からほぼ拮抗の48:52へ修正した。なお9/13(日)も市場は実質休場であり、方向性自体が出にくい点は前回・前々回の週末レポートと同様である。

## 注意すべきイベント・レベル
- 9/15〜16(火・水)の米FOMC。CPI上振れを受け利上げ織り込みは約9割まで上昇しており、実際の利上げの有無とドットチャート・ウォーシュ議長会見の内容に注目。
- 9/17〜18(木・金)の日銀金融政策決定会合。政策金利を1.25%程度へ引き上げる観測が大勢だが、0.50%への大幅利上げとなればサプライズ的な円買いのリスクがある一方、想定通りの利上げでは「材料出尽くし」で円が買われにくいとの見方もある。
- 外為どっとコムの来週(9/14〜9/20)想定レンジは152.00〜157.50円。155.00円ラインが引き続き上値の目安、153円台前半(9/11安値近辺)が下値の目安として意識される。
- CFTC投機筋の円ポジション動向(ネットロング転換報道の真偽含む)は、FOMC・日銀会合の結果次第で相場のボラティリティを左右し得るため引き続き要確認。
- 中東(イラン・サウジ)情勢の緊迫化に伴う原油価格の動向(WTI103ドル台、ブレント108ドル超)は、インフレ懸念とリスクセンチメントの両面から相場に影響しうるため引き続き注視が必要。
- 財務省・日銀による介入警戒、およびベッセント米財務長官による円安けん制発言のリスクは継続的に意識される。
- シルバーウィーク(敬老の日等の連休)を控え市場参加者が減少することで、日米中銀会合通過後は方向感が出にくくなる可能性がある点にも留意。
