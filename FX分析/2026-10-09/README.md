# USD/JPY 本日の傾向 - 2026-10-09

## 結論
ロング:ショート = 52:48 (前回10/8の47:53からロング方向へ転換)

最大の変化点は、日銀・植田総裁が10/6の講演で利上げ路線継続を示しつつも10月会合での利上げを明確に示唆しなかったことで、市場が織り込む10月会合(10/29-30)の利上げ確率が約40%から約12%程度まで急低下したと報じられている点である。一方で12月会合までの利上げ確率は約90%とされ、年内利上げ自体の後退ではない。この「10月は見送り濃厚、12月に先送り」との見方は目先の円買い材料を後退させるため、前回までの小幅ショート優位から一旦ロング優位へ戻した。ただし、USD/JPYは158円台と、介入警戒ライン(160円)に接近しつつある水準にあるため、上値を追う展開には慎重さが必要であり、比率は大幅なロング転換とはせず52:48の小幅優位にとどめた。
