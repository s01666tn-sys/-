## 結論

## 前回分析との比較
前回(9/24)はロング:ショート=63:37とし、米9月PMI速報値の予想上振れと米10年債利回りの急伸(5.0685%前後)を受けたドル優位の再加速を評価していた。今回(9/25)にかけての主な変化点は、(1)米新規失業保険申請件数・カンザスシティ連銀指数・新築住宅販売件数がいずれも予想を上回るなど労働市場・実体経済の底堅さが続けて確認されたこと、(2)7年債入札の低調な結果が金利上昇圧力を追加で裏付けたこと、(3)これらを受け米10年債利回りが2007年7月以来の高水準を再更新(5.11〜5.14%程度)したこと、(4)ドル円が9/24NY市場で159円04銭まで上昇し、9/23引け(158円40銭近辺)からさらに明確なドル優位方向へ価格が動いたこと、である。一方、(5)米国株は金利急伸とイラン懸念を受け3指数そろって下落し、(6)VIXも14.81→16.10へ上昇するなどリスク回避色がやや強まった。ただし日経平均は4日続伸とリスクオン色を維持しており、これは対外的な質への逃避(円買い)というより米国内の金利上昇を起点とした株安であるため、ドル円のロング判断に対してはなお副次的な材料と位置付けた。以上を踏まえ、ロング比率を前回から63:37→65:35へさらに拡大したが、価格が既に介入警戒ゾーン(158円台後半〜159円近辺)に達していることを踏まえ、拡大幅は抑制的とした。
