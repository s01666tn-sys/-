## 前回分析との比較
前回(9/17)はFOMCのタカ派的利上げ決定を受けロング:ショート=60:40とした。今回(9/18)にかけての変化点は、(1)米新規失業保険申請件数・フィラデルフィア連銀指数がともに予想を上振れ、タカ派FOMCを裏付ける形でドル支持材料が積み上がったこと、(2)一方で米10年債利回りはFOMC後にやや低下(5.008%→4.94%)し、米国株はFOMC後の急落から反発するなど、金利面でのドル一段高の勢いはやや後退したこと、(3)最大の焦点であった日銀会合の結果発表・植田総裁会見が「明日以降」ではなく「本日中」に到来する段階に入り、既に8〜9割織り込まれた利上げが「材料出尽くし」の円売りとなるか、高田審議委員発言に象徴される機動的な利上げ姿勢の再確認が「タカ派サプライズ」の円買いとなるか、双方向のイベントリスクが目前に迫ったこと、が挙げられる。これらを踏まえ、ドル優位の基調は維持しつつも、比率は60:40から55:45へロング方向をやや縮小した。
