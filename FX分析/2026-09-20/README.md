# USD/JPY 本日の傾向 - 2026-09-20

## 結論
ロング:ショート = 60:40 (前回9/19の58:42からロング方向へやや拡大)

当日(9/20)は日曜日でキャッシュ市場は休場、かつ翌週月〜水(9/21〜23)も敬老の日・国民の休日・秋分の日で東京市場が3連休となるため、週末〜来週前半にかけては新規の実需フローが乏しく、海外勢主導・薄商いの中でのニュースフロー次第の値動きが想定される地合いである。そうした中、9/19に公表されたCFTC/IMM投機筋の円ネットポジションが前週(9/8時点)の+10,796枚から一気に+120,400枚前後へ急増しており、短期間での急激な円ロングへの傾斜は「過度に混み合ったポジション」として、材料次第での急激な巻き戻し(円ロング解消=ドル円上昇)リスクを高めている。FRBは年内追加利上げ観測が残る一方、日銀は利上げ実施後も植田総裁が次回利上げの確約を避けており、日米の金融政策スタンスの非対称性(米はタカ派継続、日はハト派的利上げ)が意識される構図に変化はない。VIX指数も9/18に14.81まで低下し落ち着いたリスクセンチメントが続いており、これはキャリー的な円売り地合いを下支えする。以上を踏まえ、方向性としてのロング優位はやや強めたが、158〜159円近辺では財務省・日銀のレートチェック(円安けん制)が既に観測されており、上値では介入警戒による重さが引き続き意識されるため、拡大幅は小幅にとどめた。
