# USD/JPY 本日の傾向 - 2026-09-04

## 結論
ロング:ショート = 30:70 (前回9/3の45:55からさらに大幅にショート優勢へ引き下げ)

最大の変化点は、9/3の東京〜NY時間にかけてドル円が160円台から一時155.86〜156.36円まで急落(1日で1.8%超)し、8月上旬以来約1カ月ぶりの円高水準となったことである。日銀・高田審議委員の「利上げは一定のペースにとらわれず機動的に、連続利上げもあり得る」とのタカ派発言を受け、市場の一部で9月会合での50bp利上げ観測まで浮上し、OIS(翌日物金利スワップ)は25bpの利上げを完全に織り込む水準となった。加えて財務省によるレートチェック観測(介入の予備段階とされる)も円買いを加速させた。米側では8月ISM非製造業指数が55.4と予想を上回ったにもかかわらず雇用サブ指数の弱さを理由にドル売りが優勢となるなど、材料が出そろってドル安・円高方向に素直に反応する地合いに変化している。本日は米8月雇用統計(日本時間21:30発表、予想NFP+5.5万人、失業率4.1%)が最大の焦点で、155円を巡る攻防が意識されている。以上を踏まえ、実勢価格の大幅な円高シフトと日銀タカ派化・介入警戒という構造変化を重視し、比率を45:55から30:70へさらに引き下げた。

## 根拠
### 金利・中央銀行

## 前回分析との比較
前回(9/3)はロング:ショート=45:55とし、9/2のNY時間にドル円が160円台から158.20円台まで急落した実勢を重視して比率を61:39から大幅に引き下げていた。本日最大の変化点は、その流れがさらに加速し、9/3中にドル円が155.86〜156.36円まで一段と下落したことである。要因として(1)高田審議委員の「連続利上げもあり得る」との一段のタカ派発言と50bp利上げ観測の浮上、(2)財務省によるレートチェック観測という介入警戒の高まり、(3)ISM非製造業指数が予想を上回ったにもかかわらずドル売りが優勢だったこと、(4)投機筋の円ショートの巻き戻しが疑われる値動きの大きさ、が挙げられる。一方、米国株は9/3に大幅反発し、FRBの9月利上げ織り込みも56〜60%程度で大きくは崩れておらず、金利差自体が急速にドル安方向へ動いたわけではない。しかし実勢価格が1日で1.8%を超える急激な円高を演じ、識者の予想レンジ自体が154.5〜157.5円へ大きく切り下がったことを最重視し、比率を45:55から30:70へさらに引き下げた。

## 注意すべきイベント・レベル
- 9/4(金)21:30(日本時間)発表の米8月雇用統計(予想NFP+5.5万人、失業率4.1%)。前回7月分が予想外の減少だったこともあり、結果次第で9月FOMC観測とドル円の方向性が大きく振れる本日最大のイベント。強ければドル買い戻しで158円方向への戻りも、弱ければ155円割れが視野に入る。
- 155.00円が心理的節目として意識されており、「155円の攻防」が本日の値動きのカギ。下抜けが進めば8月上旬以来の水準への一段の円高もあり得る。
- 160〜165円ゾーンは従来から介入警戒水準とされてきたが、直近は156円台まで急速に押し戻されており、財務省・日銀のスタンス(レートチェック観測を含む)と、今後の口先介入の有無に引き続き注意。
- 日銀・高田審議委員の「50bp利上げ」観測の実現可能性を巡る見方は市場で割れており、9/17〜18の次回決定会合に向けて他の日銀高官(植田総裁ら)の発言が相場のタカ派/ハト派材料として一段と意識されやすい。
- 投機筋の円ショートポジションが高水準だったとみられる中での急激な円高であり、ポジション調整(踏み上げ)がさらなるボラティリティ拡大要因となり得る点に留意。
