# USD/JPY 本日の傾向 - 2026-09-10

## 結論
ロング:ショート = 23:77 (前回9/9の25:75からショート優勢をわずかに強化。ベッセント発言後も155円奪回失敗が続いていること、および本日21:30発表の米8月PPIを前にドル売り継続を予想する市場関係者の声を重視)

本日(9/10、木曜)朝のドル円は153円台半ばで推移。前日9/9はベッセント米財務長官による「(円売りに賭ける投機筋に対し)胴元は私だ、非対称な情報を持っている」との異例の口先介入を受けて一時152.94円前後までドル安・円高が進んだが、その後は中東情勢の悪化を背景とした原油価格上昇もあり下げ幅を縮小し、終値ベースでは前日比0.3%程度の下落にとどまった。外為どっとコムの本日の予想レンジは152.600〜154.400円。ザイFXの西原宏一氏は本日も「155円をあっさり割り込むか、152.10円も通過点となり150円まで下落も」との見立てを継続しており、JPモルガンのトレーディングデスクも次のFRBの一手が米国株安を招くリスクや、来週のFOMCを前に利下げ観測を織り込む形でドル売りが続く可能性を指摘していると報じられている。本日21:30(日本時間)には米8月PPI(生産者物価指数)と新規失業保険申請件数の発表を控え、ボラティリティが高まりやすい局面である。東京時間には日銀審議委員の挨拶も予定されており、タカ派的な発言が出れば昨日安値(152.94円近辺)の再試しリスクがあるとされる。以上、155円奪回失敗が3日連続で続いていること、ベッセント発言によるドル高けん制の効果が薄れていないこと、PPIを前にした市場のドル売り継続予想を総合的に重視し、比率を25:75から23:77へショート優勢をわずかに強めた。ただし中東情勢に伴う原油高・インフレ懸念の再燃と、自民党総裁選への思惑という新たな政治リスクが両にらみの要因として残っている点には留保が必要。
