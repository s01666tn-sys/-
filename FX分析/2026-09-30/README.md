# USD/JPY 本日の傾向 - 2026-09-30

## 結論
ロング:ショート = 55:45 (前回9/29の57:43からロング比率をやや引き下げ)

米イラン間の軍事衝突が実際の空爆・ミサイル応酬まで激化し、9/29のNYダウが一時900ドル超安となるリスク回避色が強まった一方、同じ地政学リスクを背景にWTI原油が7%近い急騰となり米長期金利上昇・日米金利差というドル買い材料も併存する「綱引き」状態が継続している。月末・四半期末のフロー要因やADP雇用統計等の指標発表も控え不確実性が高いため、前回よりロング優位をやや弱めた中間的な比率とした。

前回(9/29)はロング:ショート=57:43とし、口先介入の効果が「一時的」との見方が広がったことと原油高を手掛かりとした米長期金利の19年ぶり高水準更新を背景に、前々回(9/28、54:46)からロング比率を引き上げていた。今回(9/30)にかけての主な変化点は、(1)米イラン間の緊張が実際の空爆・ミサイル応酬という軍事衝突に発展し、9/29のNYダウが一時900ドル超安となるなど株安・リスク回避色が一段と強まったこと、(2)同じ地政学リスクを背景にWTI原油が6.6%高と急伸し、インフレ・米金利高を通じたドル買い材料も同時に強まったこと、(3)米10年債利回りは高水準を維持しつつも上昇一服との報道が出てきたこと、である。ドル買い材料(金利差・原油高)とリスク回避のJPY買い材料(株安・地政学リスクの実体化)が拮抗する中、地政学リスクの「実体化」による下振れ余地も意識し、ロング比率を前回からやや引き下げた。
