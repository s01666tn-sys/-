# USD/JPY 本日の傾向 - 2026-09-28

## 結論
ロング:ショート = 54:46 (前回9/27の61:39からロング比率を大きく引き下げ)

9/23の日米首脳会談でトランプ大統領が高市首相に円安への懸念を直接伝えたと片山財務相が明らかにし、これを受けて日米当局の相次ぐ口先介入(円安けん制)が強まったことで、ドル円は9/28朝時点で157円台前半まで軟化した(前営業日比約1円の円高)。為替を首脳会談級の議題とするのは異例であり、市場心理面でのドル円上値抑制材料として新たに重く見る必要がある一方、FRBの10月利上げ織り込み(約65〜73%)、米10年債利回りの19年ぶり高水準、株高・低VIXのリスクオン地合いといった金利差・センチメント面でのドル優位のファンダメンタルズ自体は崩れておらず、10/2の米雇用統計という最大の関門も控えている。この綱引きを踏まえ、ロング優位は維持しつつも比率を前回から大きく引き下げた。
