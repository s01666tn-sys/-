# USD/JPY 本日の傾向 - 2026-09-09

## 結論
ロング:ショート = 25:75 (前回9/8の28:72からショート優勢をさらに強化。155円奪回の失敗が確定したことと、ベッセント米財務長官による円安けん制発言、日本GDP改定値の上方修正確定を重視)

本日(9/9、水曜)朝の東京〜NY市場でドル円は153円台後半〜154円台で推移し、前日9/8に明確に下抜けた155円ラインの奪回に失敗した。外為どっとコムは本日午前の予想レンジを152.900〜154.500円としており、「NY勢が復帰したものの155円回復ならず」との見出しで、ベッセント米財務長官の発言が上値の重しになっているとの見方を伝えている。ベッセント長官は9/9朝、「円相場に介入する際、私は的確な見通しを持っている」「円相場で私に反して賭けてみよ、私には情報がある」との趣旨の発言をしたと報じられ、円安(ドル高)方向への一段の進行をけん制する内容と受け止められている。ザイFX(西原宏一・叶内文子両氏)は「155円をあっさり割り込むか、152.10円も通過点となり150円まで下落も」と明確な下値目線を示し、ベッセント長官の円安けん制と日銀の利上げ加速観測を背景に戻り売り継続を予想している。加えて、9/8発表の日本4-6月期GDP改定値は速報の年率+1.1%から+1.4%へ上方修正され、設備投資の下振れ縮小・個人消費のプラス転換も確認されたことで、9/17〜18の日銀会合での利上げ観測を後押しする材料が確定した。一方、米側では新FRB議長ケビン・ウォーシュ氏のタカ派スタンスの下、9月FOMC(9/15〜16)の利上げ織り込みはなお五分五分(50〜57%程度)で推移し、米10年債利回りも4.79%と高止まりしているものの、9/8の米国株はS&P500▲0.6%・NYダウ▲1.2%・NASDAQ▲0.3%と続落し、原油高(ブレント99.50ドル接近)と米加貿易摩擦激化がリスクオフ要因となった。日経平均VI(ボラティリティ指数)は9/8に前日比+46.6%の32.05へ急伸しており、日本株サイドのボラティリティ拡大も円買い(キャリー巻き戻し)方向に作用しやすい地合いである。以上、155円奪回失敗というテクニカルな弱さの確定、ベッセント発言という新たな円安けん制材料、GDP上方修正確定によるBOJタカ派観測の裏付けを総合的に重視し、比率を28:72から25:75へショート優勢をさらに強めた。
