# USD/JPY 本日の傾向 - 2026-08-28

## 結論
ロング:ショート = 57:43 (ドルやや優勢、前回56:44からわずかに強め)

ドル円は実勢として8/27に159.52円前後まで上値を伸ばし、米10年債利回りは4.67~4.68%へ反発(8/26の4.64%からの低下分を打ち消す動き)、米国株もS&P500+0.42%・ダウ+0.83%・NVIDIA+8.64%と堅調で、VIXは15.21まで低下と落ち着いたリスクオン地合いが続いている。最大の焦点だった氷見野日銀副総裁講演(8/27)は、9月会合での利上げ検討に言及したものの、時期・ペースについて明確な「予告」は避けたため、市場では一部ハト派的と受け止められ円が売られた。これらを踏まえ前回56:44からわずかにドル優勢方向へ調整し57:43とした。ただし本日は米東部時間10時(日本時間夜11時頃)にウォーシュFRB議長の就任後初のジャクソンホール講演と、雇用統計の年次ベンチマーク改定(予備値、最大20万人程度の下方修正観測あり)が重なる「二重の分水嶺」であり、結果次第で方向感が大きく反転しうるため優勢幅は小幅にとどめた。
