# USD/JPY 本日の傾向 - 2026-10-15

## 結論
ロング:ショート = 57:43 (前回10/14の51:49からロング方向へシフト)

本日最大の材料は、前日10/14発表の米9月CPIが事前予想を上回る「ホット」な結果となったことである。ヘッドライン前年比+3.7%(予想3.6%、前月3.4%)、コア前年比+2.6%(6月以来最高)となり、報道によれば発表後に10月FOMC(10/27-28)での利上げ観測が急上昇し、米国債が売られ(利回り上昇)、米国株が下落し、ドルが全面高となったとされる。これは前回(10/13〜10/14)までに確認していた「ウィリアムズ・ジェファーソン発言により利上げ観測が約70%→20〜25%に後退」という構図を一転させる、CPI結果判明という決定的な新規材料であり、ドル買い方向への明確な転換点と判断した。一方で、日銀は植田総裁が10/6講演で2%物価目標達成に向けた利上げ継続方針を改めて示しており、BOJのハト派傾斜は確認されていない点、および160円接近時の為替介入警戒(片山財務相の過去のけん制発言)がドル高の進行を抑制しうる点を踏まえ、比率は57:43とロング優位をやや強める程度の調整にとどめた。
