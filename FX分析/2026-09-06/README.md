# USD/JPY 本日の傾向 - 2026-09-06

## 結論
ロング:ショート = 33:67 (前回9/5の35:65からショート優勢をやや強め、日銀タカ派・GDP改定値待ちを重視)

本日(9/6)は日曜日でインターバンクFX市場は実質休場であり、値動き自体は限定的とみられる。ただし週明け以降を見据えた地合いとしては、9/5の財経新聞「為替週間見通し」が9/8週について「下げ渋りか」との見出しで、日銀審議委員のタカ派的な見解を受けた引き締めペース加速観測から円買い主導の展開継続を予想しており、直近のドル円実勢も9/5朝時点で156.23円前後まで反落(前日終値157.03円)、9/3には155.30円まで円高が進む場面があるなど、160円台からの調整局面が続いている。9/4発表の米8月雇用統計(NFP+16.2万人の大幅上振れ)を受けても実勢が上値を追えていない点は、日銀の利上げ観測・介入警戒という構造要因がなお相場を支配していることを示唆する。一方で、中東(イラン)情勢を背景とした原油高がインフレ再燃懸念を通じて米長期金利を1月以来の水準(4.76〜4.81%)まで押し上げており、CME FedWatchの9月利上げ織り込みも約56%とコイントスに近い水準を維持しているため、金利差材料そのものがドル安一辺倒を正当化するわけではない。9/8(火)の日本4-6月期GDP改定値(上方修正予想)が日銀の追加利上げ観測をさらに後押しする可能性がある一方、9/11(金)の米CPIが伸び鈍化となればドル売り、上振れればドル買い戻しの材料になりうる。以上を踏まえ、休場で新規材料に乏しい中、直近の実勢の弱さと来週の下げ渋り予想・GDP改定値への警戒を反映し、比率を35:65から33:67へわずかにショート優勢を強めた。

前回(9/5)はロング:ショート=35:65とし、米8月雇用統計の大幅な上振れ(NFP+16.2万人)によるドル買い戻しと日経平均の大幅反発・VIX系指標の落ち着きを踏まえ、前々回(9/4)の30:70からショート優勢をやや弱めていた。今回(9/6)にかけては、その後もドル円実勢が157.03円から156.23円へ、さらに9/3には155.30円まで円高方向の動きが優勢な状態が続いており、強い雇用統計というドル買い材料が出た後も実勢の戻りが限定的だった点で、日銀タカ派化・介入警戒という構造要因の強さが改めて確認された。また9/5付の財経新聞の週間見通しが明確に「下げ渋り」(円買い継続)を予想し、9/8のGDP改定値上振れ観測も新たな円買い材料として意識され始めている。一方で中東情勢を背景とした米長期金利の上昇(1月以来の高水準)は新たなドル支援材料であり、FRBの9月利上げ織り込みも約56%とコイントス状態を維持しているため、一方的な円高シナリオへの転換とまでは言えない。以上を総合し、比率を35:65から33:67へわずかにショート優勢方向へ修正した。
