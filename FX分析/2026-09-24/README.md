# USD/JPY 本日の傾向 - 2026-09-24

## 結論
ロング:ショート = 63:37 (前回9/23の58:42からロング方向へ拡大)

9/23のNY市場では、米9月PMI速報値(製造業・サービス)が予想を上回り約5年ぶりの高水準となったことを受け、米10年債利回りが一時5.0685%前後まで急伸、2007年7月以来約19年2カ月ぶりの高水準を記録した。同日実施された700億ドル規模の米5年債入札も最高落札利回り5.033%(2006年6月以来の高水準)・応札倍率2.21倍(過去6回平均2.33倍を下回る)と需要の弱さを示し、金利上昇圧力を裏付けた。FRBのバー理事が追加利上げの必要性を指摘したことも加わり、ドル円は157円台後半から158円40銭近辺まで上昇し、前日(9/22)引けの157円36銭から明確にドル優位方向へ動いた。一方で米国株は同日、10年債利回り急騰を嫌気してS&P500・ナスダックがそろって反落しており、「強い指標→金利高→株安」という株式サイドのリスク回避も同時進行しているが、これは対外的なリスクオフ(質への逃避)ではなく米国内の金利上昇を起点とした動きであるため、円買いには直結しにくい。以上より、日米金利差拡大というドル優位の骨格が実際の価格上昇(157円台後半→158円台)として明確に表れたことを重視し、ロング比率を前回から拡大した。ただし158円台は先週末に財務省・日銀のレートチェック観測が出た水準に近く、160円方向では介入警戒がさらに強まりやすいこと、イラン情勢の帰趨次第で原油・金利観測が反転しうることを踏まえ、拡大幅は抑制的とした。
