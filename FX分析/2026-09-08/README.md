# USD/JPY 本日の傾向 - 2026-09-08

## 結論
ロング:ショート = 28:72 (前回9/7の32:68からショート優勢をさらに強化。実勢が155円ラインを明確に下抜けたことと、CFTC円ネットショート拡大の確定を重視)

本日(9/8、火曜)朝の東京市場でドル円は154円前半まで下落し、これまで強力な下値支持として機能してきた「155円ライン」を明確に下抜けた。外為どっとコムは本日の予想レンジを153.500〜155.300円としており、テクニカル的・実需的に円買い戻し圧力が優勢な地合いが継続しているとの分析を示している。前日9/7(月)は米国がレイバーデーで休場だったため材料難の中、155.80〜156.28円のレンジで小動きにとどまっていたが、休場明けの本日になって一段の円高が進行した格好である。加えて、9/6付のCFTC/IMM投機筋ポジションでは円ネットショートが▲63.3千枚から▲92.2千枚へ拡大したことが確定しており、投機筋がなお円売り(ドル買い)に傾いた状態でドル円が下落していることから、含み損拡大による踏み上げ(ショートカバー)リスクが一段と高まっている。米金利面では、FRBの9/15〜16FOMCでの利上げ織り込みはむしろ後退気味で、Kalshiでは据え置き73%・利上げ26%との報道もある。以上、実勢の155円割れという明確なブレイクと、踏み上げリスクを内包した投機筋ポジションの偏りを重視し、比率を32:68から28:72へショート優勢をさらに強めた。ただし本日8:50発表の日本GDP改定値と週末にかけての米CPIなど不透明要因は残る。

## 前回分析との比較
前回(9/7)はロング:ショート=32:68とし、BOJタカ派観測の前倒し観測と実勢の下値模索継続を重視していたが、CFTCポジションのネットショート拡大については集計時点が不明瞭として「情報の確度に留保あり」とし、判断材料としての重みを限定的に扱っていた。今回(9/8)にかけては、(1)9/7の米国レイバーデー休場を経て、休場明けの本日朝にドル円が154円前半まで下落し、前回懸念していた「155円割れ」が実際に発生したこと、(2)前回留保していたCFTCの円ネットショート拡大(▲63.3千枚→▲92.2千枚)が9/6付データとして確定したことが、新たな変化点である。実勢の明確な155円割れと、含み損を抱えた投機筋ポジションによる踏み上げリスクの高まりを合わせて考えると、円高方向への圧力がより強まったと判断できる。一方、FRBの9月利上げ織り込みはむしろ後退気味(Kalshi: 据え置き73%)であり、ドル買い材料の勢いは前回に続き弱いままである。以上を総合し、比率を32:68から28:72へショート優勢をさらに強めた。
