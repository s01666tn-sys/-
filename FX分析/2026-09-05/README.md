# USD/JPY 本日の傾向 - 2026-09-05

## 結論
ロング:ショート = 35:65 (前回9/4の30:70からショート優勢をやや弱め、ドル買い戻し方向へ小幅修正)

最大の材料は9/4(日本時間21:30)発表の米8月雇用統計で、非農業部門雇用者数(NFP)が前月比+16.2万人と市場予想(+5.5〜5.6万人)を大幅に上回るポジティブサプライズとなった。前回分析で最大のリスクイベントとしていた弱い雇用統計シナリオは回避され、ドル円は156.00円前後から一時156.75円まで上昇する場面があった。しかし、日銀の9月利上げ観測(9/17〜18会合での25bp利上げをほぼ完全に織り込み)と為替介入警戒が根強く、実勢は上値を伸ばしきれず伸び悩んでいる。専門家(外為どっとコム掲載のハロンズFX)は、158.00〜158.76円(200日線・25日線)を戻りの抵抗帯、155.20〜155.00円を下値支持と位置づけ、「来週は日銀とFRBどちらの利上げ観測が主導するか」がテーマになるとしており、一方的な円高継続というより155〜158円のレンジ的な様相を強めている。日経平均は+806円と5日ぶり大幅反発し、VIXも直近で低位安定するなどリスクセンチメント自体は落ち着いており、前回の「大幅な円高シフト」を正当化した材料の一部(弱い雇用統計への警戒、株安基調)が後退した。以上を踏まえ、日銀タカ派化・介入警戒という構造的な円高要因は残存させつつ、ドル買い材料の出現とテクニカルな売られ過ぎ(RSI33.5)を反映し、比率を30:70から35:65へ小幅にショート優勢を弱めた。

## 前回分析との比較
前回(9/4)はロング:ショート=30:70とし、9/3の急激な円高(160円台→155.86〜156.36円)、高田審議委員のタカ派発言・50bp利上げ観測の浮上、財務省のレートチェック観測を重視して比率を45:55から大幅に引き下げていた。本日最大の焦点であった米8月雇用統計は+16.2万人と予想を大幅に上回り、前回懸念していた「弱い雇用統計によるドル安加速」シナリオは回避され、実際にドル買い戻しでドル円は一時156.75円まで上昇する場面もみられた。ただし、日銀の9月利上げ観測・介入警戒は根強く残り、実勢は上値を抑えられて伸び悩んでおり、専門家の見立ても155〜158円のレンジ的な値固めへと変化している。日経平均の大幅反発とVIXの落ち着きもあり、前回ほどの一方的な円高継続の緊迫感はやや後退した。以上を踏まえ、日銀タカ派化という構造的な円高要因は維持しつつ、ドル買い材料の出現とテクニカルな売られ過ぎを反映し、比率を30:70から35:65へ小幅に戻した。
