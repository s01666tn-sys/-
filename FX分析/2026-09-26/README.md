# USD/JPY 本日の傾向 - 2026-09-26

## 結論
ロング:ショート = 63:37 (前回9/25の65:35からロング方向をやや縮小)

9/26(土)は東京・NYともにキャッシュ市場が休場のため、直近の実勢は9/25(金)NY市場の内容に基づく。9/25はイラン情勢を巡る外交的な打開期待から原油価格が下落し、これが米長期金利急伸によるボラティリティ拡大(MOVE指数上昇)を和らげ、米国株はダウ+0.9%、S&P500・ナスダックも+0.5%程度と週間ベースでも上昇して引けた。VIXも14.87(前日比▲5.11%)まで低下し、リスクセンチメントは明確に改善している。ドル円は200日移動平均線を上抜けたとの報道があり、10日線・20日線のゴールデンクロス形成も伝えられるなど、テクニカル面・金利差(FRB追加利上げ観測、米10年債利回りは5%台前半で高止まり)の両面からドル優位の基調自体は維持されている。もっとも、9/25には為替オプションのインプライドボラティリティ(1週間物)が8%台後半まで急上昇したと報じられており、これは口先介入への警戒にとどまらず市場が実弾介入リスクを具体的に織り込み始めた兆候と解釈でき、160円方向への上値の重さがこれまで以上に意識される状況にある。加えて週末を挟むため、イラン情勢の帰趨や要人発言等のヘッドラインリスクにより週明けに窓が生じる可能性も否定できない。以上を踏まえ、日米金利差・リスクオン地合いを背景としたロング優位の骨格は維持しつつも、介入警戒シグナルの具体化と週末特有の不確実性を考慮し、前回からロング比率をやや縮小した。

## 前回分析との比較
前回(9/25)はロング:ショート=65:35とし、米長期金利の2007年以来の高水準更新とドル円の159円台到達という価格面での確認を主因にロング比率を拡大していた。今回(9/26)にかけての主な変化点は、(1)イラン情勢の外交的打開期待により原油安・株高・VIX低下というリスクオン方向への地合い改善が明確化したこと、(2)ドル円が200日移動平均線を上抜け、10日線・20日線のゴールデンクロスが形成されるなどテクニカル面でも上昇基調が強まったと報じられたこと、(3)一方で為替オプションの1週間物インプライドボラティリティが8%台後半へ急上昇するなど、介入警戒が単なる観測記事の域を超え市場価格(オプション市場)に具体的に織り込まれ始めたことが新たに確認されたこと、(4)週末を挟むためイラン情勢等のヘッドラインリスクによる週明けの窓開けリスクが意識されること、である。日米金利差・株高というドル優位の骨格自体は不変だが、(3)(4)を踏まえてロング比率を前回からやや縮小した。
