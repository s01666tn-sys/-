# USD/JPY 本日の傾向 - 2026-09-23

## 結論
ロング:ショート = 58:42 (前回9/22の60:40からロング方向をやや縮小)

9/22のドル円はNY市場で157円07銭〜157円60銭のレンジで推移し、157円36銭で引けた。FOMCの年内追加利上げ観測を背景としたドル買いが優勢だったが、米・イラン協議報道を受けた原油反落と米長期金利の伸び悩みがドルの上値を抑え、介入警戒感から円売りも限定的となるなど、方向感自体はドル優位を維持しつつも上下双方向の材料が拮抗した一日だった。米国株は9/22にS&P500が7,691.19(9/21の史上最高値7,764.70から反落)とまちまちの展開となり、前日までの明確なリスクオン一色の地合いはやや後退。また米9月リッチモンド連銀製造業指数が予想外に▲2(予想+2、前月+4)と2月以来のマイナスに落ち込む軟調な結果も出た(ただし市場はこれを大きく材料視せず「ドルは底堅い」との受け止め)。以上を踏まえ、日米金利差というドル優位の骨格自体は不変であるものの、前日にかけての米国株大幅高によるリスクオン加速が一服し、軟調な地区連銀指数も出たことから、ロング優位の拡大幅を前回よりやや慎重side(60:40→58:42)に戻した。9/23は東京市場が秋分の日で休場となり流動性が薄く、為替介入への思惑(先週末の日銀レートチェック)とイラン情勢が引き続き上値・下値双方のスイング材料として意識される。
