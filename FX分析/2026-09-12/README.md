# USD/JPY 本日の傾向 - 2026-09-12

## 結論
ロング:ショート = 55:45 (前回9/11の58:42からロング優勢をわずかに緩和)

9/12(土)は為替市場が実質休場のため、本レポートは9/11(金)NY市場引けの地合いの持ち越しと、来週(9/15〜16FOMC、9/17〜18日銀会合)を控えた地合いを指すものと位置付ける。9/11発表の米8月CPIはコア前月比+0.3%(予想+0.2%を上回る)と加速し、9月FOMCの利上げ織り込みは70%超から一時90%近くまで急上昇、ドル円もNY時間に154.48円まで上振れした。しかしその後は米長期金利がむしろ低下し、原油価格の上昇一服も重なって米国株(NYダウ+509.19ドル)が大きく切り返す一方、ドル円は153円台前半まで値を戻して引けており、CPI上振れに対する反応は「出尽くし」的で持続しなかった。この地合いの二面性(ホットなCPI・利上げ観測急上昇というドル買い材料と、実際の値動きはむしろ戻すという事実の食い違い)を踏まえ、前日までの明確なロング優勢からはやや慎重に構え、比率をわずかにロング方向を緩めた。来週は日米中銀の政策決定が相次ぐ最大の分岐点であり、方向感は限定的にとどめる。

## 前回分析との比較
前回(9/11)はロング:ショート=58:42とし、米8月PPI加速とFOMC利上げ織り込み急上昇を受けたファンダメンタルズの転換点を重視していた。今回(9/12)にかけての変化点は、(1)実際に発表された米8月CPIもコア前月比が予想を上回り加速し、利上げ織り込みが一時90%近くまで上昇したこと、(2)一方でドル円自体はNY時間に154.48円まで上昇した後153円台前半まで値を戻して引けており、CPI上振れに対する反応が持続しなかったこと、(3)米長期金利がCPI後にむしろ低下し、原油高一服とあわせて米国株が大きく切り返したこと、である。ホットなCPI・利上げ観測急上昇というドル買い材料と、実際の値動き・金利がむしろ落ち着いたという事実が食い違っており、前回のような明確なロング優勢の継続には慎重さが必要と判断し、比率を58:42から55:45へわずかに緩めた。なお9/12(土)は市場が実質休場であり、方向性自体が出にくい点は前回・前々回の週末レポートと同様である。
