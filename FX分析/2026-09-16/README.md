# USD/JPY 本日の傾向 - 2026-09-16

## 結論
ロング:ショート = 56:44 (前回9/15の47:53からロング方向へ明確に修正)

FOMC結果発表(9/16 14:00ET=9/17 03:00頃JST)を控えた最終局面で、米10年債利回りが5%台前半(2007年以来の高水準)まで上昇を続け、利上げ確率もCME FedWatchで84〜92%、Kalshiで83%程度まで急上昇するなど、前回時点(53〜68%との情報源が中心)から市場のFRB利上げ確信度が大きく高まったことが最大の変化点。これを受けてドル円自体も9/15夜(UTC)に155.099円まで上昇し、前回意識していた155円台の上値めど・テクニカル節目(155.20円、ヘッド&ショルダーズのネックライン)に接近・一部突破する動きとなっており、目先はドル買い優勢の地合いが強まっているとみてロング方向へ比率を修正した。ただし、(1)日銀会合は9/17〜18(結果は9/18)であり1.25%への利上げがほぼ全面的に織り込まれていること、(2)財務省高官(片山財務相・三村財務官)による155円台での投機的な動きへの警戒発言・介入警戒が継続していること、(3)米国株が10年債利回り上昇を嫌気して9/15に続落しリスクオフの芽もくすぶっていること、(4)FOMC自体は「材料出尽くし」による反落(ドル売り)リスクも意識されることから、大幅な修正は避け56:44の小幅ロング優勢にとどめた。
