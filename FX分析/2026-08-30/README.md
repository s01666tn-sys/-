# USD/JPY 本日の傾向 - 2026-08-30

## 結論
ロング:ショート = 58:42 (ドル優勢は継続もやや慎重化、前回60:40からわずかに引き下げ)

前回(8/29)分析後、ドル円は8/28のNY市場で実際に節目の160円を突破し、159.41円まで下押す場面を挟みつつ160.20円で引けた。7/30の日米協調為替介入以来初めて160円台を回復したことになり、ウォーシュFRB議長のタカ派講演を受けたドル優勢トレンドが実勢でも確認された点はポジティブ。一方で、8/31~9/1(米東部時間)に米ノースカロライナ州でG20財務相・中央銀行総裁会議が開催され、片山財務相とベセント財務長官が協調介入の効果や為替動向について協議する予定であり、片山財務相はかねて「更なる協調介入も躊躇しない」と表明している。介入が過去最大規模(12~13兆円)で実施された直後に節目の160円を上抜けたタイミングでのG20開催は、当局による円安けん制発言や新たな介入への警戒を強めやすい。加えてCFTC/IMM投機筋の円ネットショートは直近で拡大しており(後述)、ポジション面でも巻き戻しリスクが積み上がっている。トレンド・実勢は明確にドル優勢だが、これらの当局・ポジション要因を踏まえ、比率は60:40から58:42へわずかに慎重化させた。なお本日8/30(日)は市場が実質休場のため新規のファンダメンタルズ材料は乏しい。
