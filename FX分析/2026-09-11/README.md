# USD/JPY 本日の傾向 - 2026-09-11

## 結論
ロング:ショート = 58:42 (前回9/10の23:77から一気にロング優勢へ転換)

前日9/10発表の米8月PPIが前年比+5.4%(予想+5.3%)と市場予想を上回って加速し、長期金利上昇とともにドル買いが強まり、NY時間には一時154.67円まで急伸(その後153.85円まで反落して引け)。これを受けてCME FedWatch等が示す9月FOMCでの利上げ織り込みは前日までの48〜57%程度から70%超へ急上昇したと報じられており、外為どっとコムなど識者筋は本日(9/11)発表の米8月CPI次第で155円を試す展開を予想している。155円奪回失敗が続いていたこれまでのショート優勢トレンドに対し、ファンダメンタルズ面で明確な転換点が生じたと判断し、比率を大きくロング方向へ修正した。ただし本日発表の米CPI結果が最大の分岐点であり(コア上振れ→ドル高継続、下振れ→再び下値模索)、日銀のタカ派的リプライシング(9月利上げ観測)や中東情勢に伴う原油高・地政学リスクも円買い要因として残存するため、ロング優勢はあくまで「やや優勢」にとどめた。
