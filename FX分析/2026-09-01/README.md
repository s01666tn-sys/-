# USD/JPY 本日の傾向 - 2026-09-01

## 結論
ロング:ショート = 56:44 (ドルやや優勢は継続も、160円定着失敗とG20での円安けん制を受け前回57:43からわずかに引き下げ)

FRBのウォーシュ議長のタカ派講演を受けた9月利上げ織り込みは、CME FedWatchで前回確認時の55.7%から8/31時点で60〜66%程度へさらに切り上がっており、金利差材料自体はドル優勢方向を支えている。一方で実勢のドル円は8/31朝方に160.20円前後まで上昇する場面があったものの、160円台への定着に失敗し159.47〜159.75円まで反落して引けており、9/1朝の外為どっとコムも「円買い介入への警戒感などを背景に上値の重い展開」(予想レンジ159.20〜160.40円)と、160円台では上値が重いとの見方を継続している。さらに8/31〜9/1(米東部時間)開催のG20財務相・中央銀行総裁会議では、ベセント米財務長官が「日本政府と日銀が、より強い円につながる措置を講じると確信している」と改めて円安是正を日本側に求めたと報じられており、協調介入への警戒感が高まりやすい局面が続く。株式市場・VIXの変化は小幅で明確な方向感は出ていない。以上を踏まえ、金利差材料によるドル優勢の基調は維持しつつ、価格自体が160円定着に失敗しG20で円安けん制姿勢が強まっていることを反映し、比率を57:43から56:44へわずかに引き下げた。
