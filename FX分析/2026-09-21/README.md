# USD/JPY 本日の傾向 - 2026-09-21

## 結論
ロング:ショート = 58:42 (前回9/20の60:40からロング方向をやや縮小)

当日(9/21、月)は敬老の日で東京市場が休場となる3連休(9/21〜23)の初日であり、9/21早朝(日本時間6〜7時台)のドル円は156円68銭〜156円96銭前後と、前週末9/18のNY引け値156円60銭からほぼ横ばい〜小幅高にとどまっており、週末を挟んでも方向性を明確に示す新規材料は乏しい。一方、日銀の植田総裁の9/18会見内容について、事後の報道では「政策の局面が変化した」「物価の上振れリスク次第では連続・大幅な利上げも排除しない」との、従来の「次回利上げは確約せず」という単純な緩和的トーンよりもやや踏み込んだハト派修正(=タカ派寄り)の論調も見られ、CFTCの円ネットロング急増(過度に混み合ったポジション)によるドル円上昇リスクとは逆方向の材料としてやや意識される。加えて当日は日米ともに大型経済指標の発表がなく、東京市場休場による薄商いのなかで方向感に乏しい展開が想定されるため、前回強めたロング優位をわずかに巻き戻した。もっとも、日米金利差(FRB3.75〜4.00%・追加利上げ観測残存 vs BOJ1.25%)を背景とした構造的なドル優位、VIXの低位安定によるキャリー的な地合い、および混み合った円ロングの巻き戻し(スクイーズ)リスクという骨格は変わっておらず、ロング優位自体は維持した。
